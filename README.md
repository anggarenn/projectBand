# Project Band - Silly N Valley Official EPK & Web Profile

Website resmi Company Profile & Electronic Press Kit (EPK) untuk **Silly N Valley** (@silly.n.valley), unit punk rock asal Tangerang ("Highly Motivated Punk").

## Rute Utama
- `/silly-n-valley` : Halaman resmi band dengan audio tape deck, galeri foto fanzine Instagram, flyer gigs, distro merch, dan riders panggung.
- `/band` : Alias rute ringkas menuju profil Silly N Valley.

## Getting Started
```bash
npm install
npm run dev
```

Buka [http://localhost:3000/silly-n-valley](http://localhost:3000/silly-n-valley) di browser.
